# Shahin Latifi Portfolio

## Files
- `index.html` — page content
- `style.css` — responsive design and visual effects
- `script.js` — mobile menu and scroll reveal animations

## Run locally
Open `index.html` in your browser, or use the Live Server extension in Visual Studio Code.

## Publish with GitHub Pages
1. Create a new GitHub repository.
2. Upload these three files to the repository root.
3. Open Settings → Pages.
4. Choose Deploy from a branch, select `main` and `/ (root)`, then Save.

## Before publishing
- The contact button currently opens the visitor's default email app with a prepared message. Add your real email address to the `mailto:` link in `index.html`.
- The portfolio links point to the four live project URLs supplied by you.
